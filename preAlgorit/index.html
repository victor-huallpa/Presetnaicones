Problema de Canicas — UVa

Ordenamiento + Búsqueda Binaria Modificada

El objetivo es determinar si un número existe dentro de una colección de canicas y, si existe, encontrar su primera aparición.

Entrada

Consulta

x = 3

Dificultad Principal

¿Qué ocurre?

  • • Se encuentra el valor.
  • • Se guarda la posición actual.
  • • La búsqueda continúa hacia la izquierda.

Objetivo

Encontrar la posición más pequeña donde aparece el número.

Complejidad del Algoritmo

Análisis temporal

Ordenamiento

O(n log n)

Consulta

O(log n)

Total

O(n log n + q log n)

La búsqueda binaria es eficiente porque reduce el espacio de búsqueda a la mitad en cada iteración.

Código Completo

Implementación final en C++

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, q;
    int caso = 1;

    while (cin >> n >> q && (n != 0 || q != 0)) {

        cout << "CASE# " << caso << ":\n";
        caso++;

        vector<int> canicas(n);

        for (int i = 0; i < n; i++) {
            cin >> canicas[i];
        }

        sort(canicas.begin(), canicas.end());

        for (int i = 0; i < q; i++) {
            int x;
            cin >> x;

            int ini = 0;
            int fin = n - 1;
            int resultado_idx = -1;

            while (ini <= fin) {
                int mit = (ini + fin) / 2;

                if (canicas[mit] == x) {
                    resultado_idx = mit;
                    fin = mit - 1;
                }
                else if (x > canicas[mit]) {
                    ini = mit + 1;
                }
                else {
                    fin = mit - 1;
                }
            }

            if (resultado_idx != -1) {
                cout << x << " found at "
                     << resultado_idx + 1 << "\n";
            }
            else {
                cout << x << " not found\n";
            }
        }
    }

    return 0;
}
