06

Encontrar Máximo Elemento

PROBLEMA

Hallar el elemento más grande

Encontrar y retornar el valor máximo dentro de un arreglo de números.

Entrada: [3, 7, 2, 9, 5]
Salida: 9
06

Máximo → Solución

SOLUCIÓN

Recorrido y Comparación

1
Inicializar max con primer elemento
2
Recorrer desde segundo elemento
3
Si actual > max, actualizar max
4
Retornar máximo encontrado
Complejidad: O(n)

Conclusiones

⚡

La elección del algoritmo afecta el rendimiento

📊

Análisis de complejidad es fundamental

🎯

Recursión y iteración son complementarias

🚀

Estructuras de datos organizadas mejoran búsqueda

Estrategia

  • Dividir el arreglo continuamente.
  • Usar:
  • ini → inicio
  • fin → final
  • mid → punto medio

Complejidad

O(log n)

Pseudocódigo


while(ini <= fin){

    mid = (ini + fin) / 2;

    if(arr[mid] == x){
        return mid;
    }

    if(x > arr[mid]){
        ini = mid + 1;
    }else{
        fin = mid - 1;
    }
}
