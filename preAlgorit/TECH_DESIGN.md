## 📐 ESTRUCTURA VISUAL

### Slide de Problema
- Header accent (línea degradada)
- Número de slide (01, 02, etc.)
- Título descriptivo
- Badge "PROBLEMA" (rojo)
- Descripción del issue
- Código de ejemplo
- Separación clara

### Slide de Solución
- Mismo formato que problema
- Badge "SOLUCIÓN" (verde)
- Steps numerados o estructura concreta
- Complejidad algorítmica
- Información técnica clara

### Elementos Interactivos
- **Step Cards**: Con número, descripción, hover effect
- **Case Boxes**: Para casos base/recursivos
- **Code Blocks**: Con estyling mono
- **Elements**: Visualización de arrays
- **Complexity Tags**: O(n), O(log n), etc.
